      O que acontece

      1. ValidaçãoO ZIP é conferido e cada faixa é identificada pelo participante.
      2. PreparaçãoRuntime e modelo necessários são baixados e verificados automaticamente.
      3. TranscriçãoAs faixas são processadas separadamente, com checkpoints para sessões longas.
      4. Linha do tempoOs turnos são alinhados e reunidos sem misturar as vozes de origem.
